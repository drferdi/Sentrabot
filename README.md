### 01 / ORIGIN SIGNAL

[Sentra](https://sentrahai.com/) is built to make complex workflows feel simpler, faster, and more approachable. **Sentra Bot** is the operating layer of that idea — persistent, composable AI teammates you actually own, running against your own models, your own data, and your own machines.

Rather than another chat that ends when the tab closes, Sentra Bot keeps working: bots carry memory across conversations, wake on routines, and act inside shared or private computers. The goal is practical autonomy — useful only because it stays inside a boundary where a human holds the final key.

This repository contains the engine behind [Sentra Bot](https://sentrahai.com/): the API, the desktop app, the worker where routines run, and the RME bridge for clinical record reconnaissance.

### 02 / DOCTRINE

> [!IMPORTANT]
> **AI should not perform. It should hold.** Useful, humble, explainable, safe — or it doesn't ship.

<table>
<tr>
<td width="50%" valign="top">

**THE HUMAN HOLDS THE KEY**

Every system terminates at a human reviewer. The machine proposes, structures, retrieves. It never signs. Final authority is a boundary.

</td>
<td width="50%" valign="top">

**READ-ONLY UNTIL PROVEN**

Clinical layers (like the RME adapter) start strictly read-only. No write reaches a patient record until the read path is verified end to end.

</td>
</tr>
<tr>
<td width="50%" valign="top">

**BYOD · MODELS & COMPUTERS**

Bring your own model and computer provider — or run the whole stack locally. No lock-in to a single vendor.

</td>
<td width="50%" valign="top">

**SEPARABLE BY DESIGN**

Reasoning, memory, orchestration, computers, security — each module can be inspected and replaced without the others noticing.

</td>
</tr>
</table>
